# Organic

## Use when

适合自然、健康、教育、照护、手作、社区、食品和强调亲和关系的个人或组织网站。

## Avoid when

高精度工程工具、实时交易、严肃数据监控或需要冷静技术权威的产品，不要用柔软表面掩盖信息密度。

## Typography

使用 humanist sans、温和 serif 或具有手工细节的 display face。正文保持开放字面、舒适行高和自然段落节奏。

## Palette character

从真实环境和材料取色，例如叶、土、陶、织物、木和自然光。避免把“organic”简化成米色、鼠尾草绿和棕色固定套装。

## Layout and hierarchy

使用柔和不对称、呼吸空间和内容驱动的曲线或裁切。信息关系仍需清楚，不能用自由形状破坏扫描路径。

## Surface and depth

可使用轻微纹理、柔和边缘、层叠纸面或自然阴影。控制圆角种类，避免所有组件都变成胶囊。

## Motion

缓慢、低幅、类似呼吸或生长的 motion 只用于一个环境时刻；交互反馈仍要即时。

## Signature candidates

可选择与主题相关的季节变化、材料纹理、手绘数据形态、成长路径或一个可探索的自然分类结构。

## Defaults to reject

拒绝固定 beige-sage palette、随机 blob、叶子图标遍布和过度柔焦摄影。用主题实际材料和具体故事替代。

## Responsive behavior

小屏简化自由形状和 overlap，保证正文、表单和 CTA 顺序稳定；装饰媒体不能造成布局跳动。

## Accessibility risks

低对比自然色、纹理背景和细 serif 容易影响阅读；不要只靠颜色区分类别或状态。

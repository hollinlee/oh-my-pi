# Editorial

## Use when

适合文章、评论、文化项目、出版物、作家主页和以叙事或观点为核心的作品集。

## Avoid when

高频操作型 dashboard、密集配置界面或用户需要快速完成重复任务时，不应让杂志构图妨碍效率。

## Typography

使用有鲜明语气的 display serif 或 humanist face，与高可读正文和克制 utility face 配对。重视 measure、leading、首段、pull quote 和 caption 的关系。

## Palette character

从纸张、油墨、档案、摄影或主题文化中取色。通常以低饱和基础色承载长读，再用一个编辑强调色建立节奏。

## Layout and hierarchy

使用不对称 columns、跨栏标题、边注、caption 和内容节拍。结构应像编辑选择，而不是把组件排成模板 section。

## Surface and depth

主要依赖排版、规则线、图片裁切和纸面色差。避免高密度圆角卡片与浮层阴影。

## Motion

可用章节进入、图片揭示或 typography transition 服务阅读节奏。长读中避免持续运动和 scroll hijacking。

## Signature candidates

可选择随阅读位置变化的 running header、主题化目录、边注系统或一个独特图文跨栏构图。

## Defaults to reject

拒绝无理由的报纸三栏、装饰性 `01/02/03`、所有标题都用超大 serif。用真实文章结构、内容层级和编辑节奏替代。

## Responsive behavior

小屏优先正文 measure 和阅读顺序；边注转为 inline note，跨栏元素回到单列，保持 caption 与媒体关联。

## Accessibility risks

Display serif 不能承担小字号正文；pull quote 不应重复给 screen reader；复杂视觉顺序必须保持合理 DOM 顺序。

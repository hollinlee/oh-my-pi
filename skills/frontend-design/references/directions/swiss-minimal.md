# Swiss Minimal

## Use when

适合研究、工程、咨询、公共信息和需要长期耐看的个人网站；内容价值来自清晰、可信和可扫描性。

## Avoid when

主题依赖丰富感官氛围、亲密手作感或戏剧化叙事时不要默认使用。不要把它理解成“全白 + Helvetica”。

## Typography

使用中性但有细节的 grotesk 或 neo-grotesk 作为主字体，可用 mono 处理索引和 metadata。通过字级、字宽、基线和留白建立权威，不依赖粗体泛滥。

## Palette character

以纸白、墨黑和一个功能性强调色为核心。强调色用于导航、状态或关键链接，不作为随机装饰。

## Layout and hierarchy

采用明确 columns、基线节奏和非对称但可解释的 grid。让标题、索引、日期和正文形成编辑秩序；使用对齐和空间而非大量容器。

## Surface and depth

接近平面。Hairline、规则线和局部底色用于表达结构；阴影极少。

## Motion

使用精确的短 transition、导航状态和单次进入编排。Motion 应像排版变化，不像漂浮物理效果。

## Signature candidates

可从动态索引、可折叠项目年表、贯穿页面的基线或主题相关的数据标尺中选择一个。

## Defaults to reject

拒绝无内容理由的巨大无衬线标题、三列能力卡片和红黑白“瑞士海报”模仿。用真实内容关系和可识别 grid 替代。

## Responsive behavior

小屏保留层级顺序和基线节奏，将 columns 折叠为单列；索引和 metadata 不应压缩正文宽度。

## Accessibility risks

Hairline 和浅灰文字可能对比不足；过密的全大写标签影响可读性；依赖位置表达关系时应补充语义结构。
